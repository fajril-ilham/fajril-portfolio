Tentang Saya

Saya adalah siswa jurusan Rekayasa Perangkat Lunak (RPL) di SMKN 1 Purwosari yang berfokus pada Pengembangan Web dan UI/UX Design. Saya memiliki semangat tinggi untuk terus mempelajari teknologi terbaru di dunia industri. Saat ini saya aktif mengasah kemampuan dari tahap perancangan desain antarmuka berbasis pengguna hingga proses pembuatan sistem web dinamis. Saya selalu siap beradaptasi dengan alur kerja tim dan tantangan baru. Lewat kegiatan PKL ini, saya ingin mengaplikasikan skill yang saya miliki, mencari pengalaman langsung di industri software house, dan berkontribusi aktif dalam proyek tim.
